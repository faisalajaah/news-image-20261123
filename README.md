The World Today — Monday 23 November 2026. A one-page newspaper front page drawn entirely in code: twenty stories from 23 November 2026, each checked against its source for that date. Ukraine sinks the Russian corvette Merkury off Libya; COP31 collapses in Antalya; Russian strikes kill 14 around Kyiv as new talks are signalled; markets bounce after Friday's AI rout; Democrats clinch 258 House seats — plus briefs and an also-today strip spanning NATO, the EU, Iran, Indonesia, Delta, Belgium, sport, science and tech. The program is pure Node 22 standard library, draws the 1024x1024 PNG with its own 5x7 pixel font and PNG encoder, and is fully deterministic.
